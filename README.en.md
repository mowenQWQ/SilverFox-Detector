# SilverFox Detector (银狐特攻) — Stubborn Trojan Scanner & Killer

> **Author**: MoWenQWQ (莫问QWQ) · **License**: MIT · **Version**: v2.15.75 · **Engine**: PowerShell v1.94
> [中文](./README.md) | **English**

An open-source Windows security utility focused on **SilverFox-class persistent trojans** —
full-chain detection, security-software restoration, and a "newcomer-friendly" UX with
a **live GUI progress panel**.

## Why

SilverFox (银狐) malware family is a notorious Chinese threat that:
- Masquerades as system processes and disables security software (Defender policies,
  whole-drive exclusions, UAC off, firewall off, IFEO hijacks, service disabling,
  self-start deletions, DNS hijacking, fake root certificates),
- Downloads secondary loaders (VBS/Office macros) and forces a reboot
  (`shutdown /r /f /t 0`) to make its tampering take effect.

This tool reverses every one of those behaviors into **detection + repair**.

## Architecture

- **Main program (Go)**: native Win32 GUI (no UI framework), engine scheduling, UAC
  orchestration, self-protection (anti-freeze / watchdog / integrity signing) and a
  built-in **independent PowerShell downloader** (never uses PowerShell to download PowerShell).
- **Detection engine (PowerShell 5.1/7)**: 9-stage pipeline with heuristic scoring +
  IOC matching, running in its own console, streaming progress to the GUI panel.
- **Data layer**: IOC library (domains / hashes), whitelist & trust sets, observation
  list, quarantine (recoverable).

### Pipeline (9 stages)
`[1/7]` process/commandline → `[2/7]` file (MZ spoof/signature/hash/IOC) →
`[3/7]` registry autostart → `[4/7]` scheduled tasks (Win7 compatible) →
`[5/7]` services (drivers / IFEO) → `[6/7]` outbound C2 → `[7/7]` WMI persistence →
`[8]` certificate trust chain → `[9]` Defender exclusions.

## Features

- 【专杀扫描 / Quick Scan】 default GUI mode: full 9-stage health check.
- 【全盘检测 / Full Scan】 every fixed partition, full recursion (deep).
- 【系统诊断 / 恢复隔离文件 / 系统修复】 Diagnostics, quarantine restore, hosts/DNS/proxy/Winsock repair.
- 【恢复杀毒软件 / Restore Security Software】 17 stages: Defender policies & client
  settings, UAC, system tools, Windows Update, services, exclusions, hosts, processes,
  autostarts, tamper protection, proxy/DNS, firewall, Defender engine status, IFEO,
  certificates, before/after comparison, and **third-party AV takeover detection**
  (no false alarms when 360/Huorong is present) + **"security software wiped" detection**.
- 【网络封锁管理 / Network Block Manager】 view/remove malicious-connection blocks.
- 【安装 PowerShell / Install PowerShell】 built-in Go HTTP downloader when missing.
- GUI progress panel always visible (even if the console window renders black).

## Security Statement (for reviewers)

This is a **defensive** security tool:
- **Self-protection** (anti-freeze / EDR-freeze detection / thread resume / process
  monitoring / SeDebugPrivilege for reading process info) exists only to counter
  malware killing or freezing the tool itself. Not offensive.
- **Elevation** is only requested when repair (registry/services/hosts) requires admin.
- **IOC data**: public threat intel (SilverFox samples). Test-sample hashes are harmless.
