一款面向 Windows 的**银狐类顽固木马专杀与安全体检工具**,主打"小白友好"、
"全链反推"与"实时进度可视化"。

## 软件架构与设计

本工具为 **Go 主程序 + PowerShell 检测引擎** 双层架构的轻量级专杀工具, 主打"全链反推、小白友好、防御优先"。

### 架构分层
- **主程序层 (Go)**: Win32 API 直调构建原生 GUI(无 UI 框架), 负责引擎调度、进度可视化、
  提权编排(UAC)、自保护(反挂起/看门狗/完整性签名)与 PowerShell 独立下载器。
- **检测引擎层 (PowerShell 5.1/7)**: 9 段扫描流水线 + 动态启发式评分 + IOC 比对,
  单进程独立控制台运行, 输出经进度文件实时同步到 GUI 面板。
- **数据层**: IOC 库(域名/哈希)、白名单与签名信任集、观察清单、隔离区(可恢复)。

### 检测管线 (9 段)

> **v1.95 新增**: `[2/7]` 内置 **PE 结构启发** —— 解析文件头节表识别"双段 overlay(尾部巨量附加数据)+加壳节(.ndata/UPX/零尺寸节)"白签名捆绑;
> 处置档 `/struct=1仅观察(默认)/2多信号叠加/3高危即隔离`; `/deep-pe` 开启导入表敏感 API(keylogger/剪贴板/注入/下载执行)扫描。
1. `[1/7]` 进程/命令行评分(伪装系统进程、强制重启等特征) → 2. `[2/7]` 落地文件(MZ 伪装/签名/哈希/IOC)
3. `[3/7]` 注册表自启动 → 4. `[4/7]` 计划任务(Win7 兼容) → 5. `[5/7]` 服务(驱动/映像劫持观察)
6. `[6/7]` 外联 C2 命中(known_c2) → 7. `[7/7]` WMI 持久化 → 8. `[8]` 证书信任链 → 9. `[9]` Defender 排除项

### 核心设计理念
- **全链反推**: 把银狐限制安全软件的常见手段(Defender 策略/整盘排除/UAC 禁用/防火墙关闭/
  IFEO 劫持/服务禁用/自启删除/DNS 劫持/代理/自签名证书)逐项反推为检测与自动修复。
- **小白友好**: 傻瓜式引导(输入序号即可处置)、分级提示(高危红/可疑黄/信息灰)、
  保守误报策略(第三方杀软接管降噪、常见公共 DNS 白名单、CA 大名单)。
- **防御优先**: 自保护(反挂起/ETW 监控/看门狗自愈/完整性签名)均用于对抗恶意软件对工具
  自身的终止/挂起, 属防御性实现。
- **便携零依赖**: 绿色单文件, `%~dp0` 相对路径; 系统缺 PowerShell 时用 Go 内置下载器
  (不依赖 PowerShell 下载 PowerShell)。

### 处置模型
- 分级: 高危(交互隔离/删除) / 待核实(报告引导) / 观察(信息)。
- 交互三选一: 隔离(可恢复) / 删除(先备份) / 跳过; 进程处置与证书隔离(备份 .cer 可恢复)。
- **恢复杀毒软件 17 阶段**: 策略/客户端设置/UAC/系统工具/WinUpdate/服务/排除项/hosts/
  进程/自启/防篡改/代理DNS/防火墙/Defender引擎/IFEO/证书/前后对比验证。

### 可靠性
- 编码与便携铁律(utf-8-sig/GBK 按文件类型, 无绝对路径); 每个阶段独立 try/catch(坏项跳过)。
- GUI 消息合并 + 尾部截断抗卡死; 引擎进程消失自动解锁按钮。
- 工具完整性自检(33 文件 SHA256 + 签名), 篡改即弹窗告警。

## 功能

- 【专杀扫描】图形化默认模式:进程/文件/注册表/计划任务/服务/网络/WMI/
  证书信任链/Defender 排除项 9 段全量体检
- 【全盘检测】所有分区 + 全深度递归扫描
- 【系统诊断 / 恢复隔离文件 / 系统修复】Hosts、DNS、代理、Winsock 修复
- 【恢复杀毒软件】17 阶段:Defender 策略/服务/排除项/UAC/防火墙/IFEO 劫持/
  第三方杀软接管识别/安全软件"被删干净"检测
- 【网络封锁管理】查看/解除恶意外联封锁
- 【安装 PowerShell】系统缺失时独立下载器(Go 内置 HTTP,零 PowerShell 依赖)
- GUI 面板实时显示扫描进度(黑窗口黑屏不影响使用)

## 安全说明 (开源审查声明)

本工具为**防御性安全工具**。部分技术点说明如下, 望审查者/使用者正确理解:

- **自保护**: 主程序含"反挂起(EDR-Freeze 检测/线程恢复)、进程监控、SeDebugPrivilege 提升只用于读取进程信息"——目的均为**对抗恶意软件对工具自身的终止/挂起**, 属防御性, 非攻击组件。
- **提权**: 修复/恢复类操作(改注册表、服务、hosts)需要管理员时自动申请 UAC, 仅为完成检测修复所需。
- **IOC 库**: ioc/ 下域名/IP/哈希为公开威胁情报(银狐木马样本), 用于比对检测。
- **测试样本哈希**: known_hashes.txt 内含无害测试文件样本(如发票_2026.png/工资表.doc.exe 的哈希), 仅用于功能验证, 无实际危害。
- **不包含**: 任何凭据/密钥/云端账号; webdav 备份脚本不在本仓库。
